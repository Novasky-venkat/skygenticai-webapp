Enterprise Governance

Privacy Policy & Data Governance

Effective Date: September 1, 2026 | Version 3.2

1. Enterprise Data Commitment

SkyGentic AI ("SkyGentic", "We", "Our") respects the strict privacy and security standards required by our enterprise clientele. This Privacy Policy details our practices concerning data collection, zero public model training policies, vector indexing isolation, and global regulatory compliance (GDPR, CCPA, HIPAA, ISO 27001).

2. Zero Model Training Policy

Strict Guarantee: Customer data, chat transcripts, database queries, and internal knowledge documents processed through SkyGentic AI services (Forge, Swarm, SkyFlow, Hive) are NEVER used to train, fine-tune, or improve public or shared foundation language models.

3. Data Collection & Usage

We collect information necessary to deliver, optimize, and secure enterprise agent infrastructure:

  • Account Credentials: Name, work email, organization details, and SSO tokens.
  • Telemetry Data: Anonymized token counts, request latency, vector query performance, and error logs for NovaOps governance.
  • System Logs: IP address, user agent string, and encrypted session identifiers for SOC-2 auditing.

4. Encryption & Security Standards

All data in transit is protected using TLS 1.3 with modern cipher suites. Data at rest (including vector indices and customer session logs) is encrypted using AES-256 with customer-managed encryption key (CMEK) support for Enterprise tier customers.

5. Your Rights & Data Deletion

Under GDPR and CCPA, enterprise customers retain full data sovereignty. You have the right to request full export or permanent cryptographic deletion of your organization's vector indices and logs at any time by contacting privacy@skygentic.ai.
